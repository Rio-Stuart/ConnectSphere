Architecture Overview

Built like a modern SaaS, engineered as a database laboratory.

Most applications treat databases as hidden black boxes. ConnectSphere makes relational database operations transparent, visual, and educational — without compromising the feel of a consumer social network.

Relational Feed

Explore personalized timelines generated dynamically using parameterized SQL queries with composite indexed joins across users, followers, and posts.

Integrity Enforcement

Foreign keys with ON DELETE CASCADE, UNIQUE email and usernames, and CHECK (follower_id != following_id) constraints enforced at the engine level.

Dual Database Bridge

Run locally on MySQL 8.0 or deploy to the cloud on Netlify PostgreSQL with seamless query interception, parameterized conversion, and zero code changes.

User Experience

A thoughtful social experience designed for clarity.

Post thoughts, code snippets, photos, and document attachments up to 15MB. Filter your feed between All, Following, and My Posts with instantaneous query execution.

  • Hashtag parsing with immediate relational aggregation
  • Threaded comment drawers with parent post context
  • Profile metrics computed dynamically with SQL subqueries
